# 🚀 BrgyConnect Launch Campaign Strategy & 4-Week Social Media Calendar

> **Campaign Slug:** `launch-campaign`
> **Date Authored:** 2026-09-01
> **Author:** Node 5 — Poster / Community Lead
> **Campaign Window:** Week 1–4 (Starting ~2026-09-08)

---

## 🎯 Campaign Brief

| Parameter | Decision |
|---|---|
| **Priority Audience** | Residents first → Businesses second |
| **Primary Channel** | Personal Facebook profile (authentic solo-builder voice) |
| **Amplification** | Barangay Daine 1 & 2 FB groups + Indang, Cavite local groups |
| **Duration** | 4 Weeks |
| **Budget** | Purely organic (zero paid ads) |
| **Hero Feature Hook** | MSME Business Directory (support local, relatable) |
| **North-Star Metric** | Site traffic → ag-brgy-connect.vercel.app |
| **Voice / Language** | Taglish, solo "ako / I" founder voice, "What Could Be" framing |

---

## 📐 Campaign Architecture: 4-Phase Funnel

```
WEEK 1: TEASE      → Create curiosity & local pride
WEEK 2: LAUNCH     → Hero reveal + MSME directory onboarding push
WEEK 3: PROOF      → Social proof, testimonials, feature spotlights
WEEK 4: COMMUNITY  → Normalize usage, feedback loop, next steps
```

## 📊 Amplification Protocol (Every Post)

1. **Post on personal profile** — fully public
2. **Within 30 minutes**: Share the same post to:
   - Barangay Daine 1 Official/Community FB Group
   - Barangay Daine 2 Official/Community FB Group
   - Indang, Cavite Community / Residents FB Group
   - Any local Cavite tech / entrepreneur groups
3. **Engagement Rule**: Reply to EVERY comment within the first 2 hours of posting
4. **DM Warm Leads**: Anyone who comments "TINDAHAN KO" or "ILISTA MO AKO" gets a personal DM with onboarding instructions
